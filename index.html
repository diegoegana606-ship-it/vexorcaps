Añadir fotos de gorras nuevas

Cuando llegue mercancía: elige la sección (Triple A o Top Quality), la categoría (una existente o una nueva), las unidades de cada gorra y sube las fotos. Cada foto es una gorra nueva con su referencia automática. Luego toca «Publicar» para que los clientes las vean.

Publicar en tu web (GitHub)

Para publicar tú solo, sin ayuda de nadie: crea en GitHub una «llave» (token) y pégala aquí. Así, al tocar «Publicar», el panel sube los cambios y Vercel actualiza tu web. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate. Elige solo el repositorio de tu catálogo y el permiso «Contents: Read and write». La llave se guarda solo en este dispositivo.
